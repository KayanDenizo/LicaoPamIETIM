# 📱 Lição PAM I (04/09/25)

Lição de PAM I: tela de cadastro em um app Android, com campos de nome, CPF, data e nome da mãe e botões de voltar e continuar.

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)

## Como rodar

1. Abra o projeto no **Android Studio**
2. Aguarde a sincronização do Gradle
3. Rode em um emulador ou em um celular com depuração USB ativada
